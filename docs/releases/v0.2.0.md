# Radiko Recorder v0.2.0

本次更新重点减少短暂网络故障造成的录音缺失。

## 更新内容

- 直播分片下载失败后自动退避重试，保留尚可用的分片地址，并从新清单更新地址；补回后按时间排序、去重封装为 M4A。
- 保存分片时间索引，重启后可继续使用已下载片段；补齐已发现的缺口后清除缺失标记。
- 按 `e` 查看选中预约的错误时间段、原因、重试次数和补取结果；按 `Shift+e` 查看试听错误，区分节目时间与前后缓冲。
- 试听遇到 404、连接中断、意外结束或长时间无音频时自动刷新会话、重连，保留音量和静音状态。
- 录制开始时再创建流会话，减少提前准备导致的地址失效；改善 Windows 原子保存遇到临时文件占用的重试。
- 保留崩溃日志、预约持久化和 FFmpeg 兼容录制路径。

## Windows x64 下载与使用

下载下面的 `radiko-recorder-v0.2.0-windows-x86_64.zip` 并完整解压。包含可执行文件、PDB 崩溃诊断符号、中文 README、许可证和 FFmpeg 安装脚本；无需安装 Rust。

在解压目录打开 PowerShell：

```powershell
# 已有 FFmpeg 可跳过此步，也可通过 --ffmpeg 指定路径
powershell -ExecutionPolicy Bypass -File .\scripts\setup-ffmpeg.ps1
.\radiko-recorder.exe JORF
```

也可双击 EXE 后输入电台 ID。FFmpeg 需另行安装，未包含在压缩包中。`SHA256SUMS.txt` 提供下载包校验和。

升级前请正常退出旧程序。保留原数据目录即可沿用预约，已有录音目录可用 `--output-dir` 指定；不要在录制中覆盖文件。

## 验证与限制

本次功能在 Windows 上通过格式、编译、Clippy、单元/协议/日志测试及本地 FFmpeg/HLS 验证，包括短暂断网、分片 404/损坏后重试、永久丢片、顺序与去重、索引恢复、产物解码、试听自动重连与取消。发布包由标签源码使用锁定依赖构建。

本次恢复功能未重新进行真实 Radiko 网络录制验证。补片受直播缓存窗口限制，服务器已删除或持续拒绝的片段可能无法补回；没有绝对分片时间或不支持的清单仍使用 FFmpeg 兼容路径。仅支持当前网络地区有权限收听的免费直播，不含回听或会员登录。其他操作系统未实机验证。
